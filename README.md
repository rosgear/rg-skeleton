## Скелет веб-приложения RosGear

Это базовая структура, лежащая в основе всех редакций веб‑приложений RosGear.

### Репозитории редакций веб-приложения RosGear использующие RG Skeleton
- [RG CMS: Редакция «Базовая»](https://github.com/rosgear/rg-cms-base)
- [RG CMS: Редакция «Cтарт»](https://github.com/rosgear/rg-cms-start)
- [RG CMS: Редакция «Cтандарт»](https://github.com/rosgear/rg-cms-standard)

### Установка

Предпочтительный способ установки через [composer](http://getcomposer.org/download/), 

или выполнить:

```
php composer.phar require rosgear/rg-skeleton "*"
```

или добавить

```
"rosgear/rg-skeleton": "*"
```

в раздел "require" вашего файла `composer.json`.

## RosGear web application skeleton

This is the basic structure that underlies all editions of RosGear web applications.

### Repositories of RosGear web application editions using RG Skeleton
- [RG CMS: Edition «Base»](https://github.com/rosgear/rg-cms-base)
- [RG CMS: Edition «Start»](https://github.com/rosgear/rg-cms-start)
- [RG CMS: Edition «Standard»](https://github.com/rosgear/rg-cms-standard)

### Installation

Preferred installation method is via [composer](http://getcomposer.org/download/), 

or execute:

```
php composer.phar require rosgear/rg-skeleton "*"
```

or add

```
"rosgear/rg-skeleton": "*"
```

to the "require" section of your `composer.json` file.
